# Every subreddit below was individually verified alive on 2026-08-13 (article

# READ THIS BEFORE PRUNING THESE. Reddit rate-limits by IP and the penalty
# ACCUMULATES, so a batch of checks poisons later ones: a single rested request
# returns HTTP 200 with our own UA, while 14 in a row return 429 for hours
# afterwards. ingest.py therefore throttles reddit.com to one request per 10s
# (REDDIT_MIN_INTERVAL), which is ~6/min against Reddit's ~10/min ceiling.
#
# That fix could NOT be confirmed locally — the test IP was already penalized
# past the point of measuring. The first Actions run is the real datum:
#   429  -> still bursting; raise REDDIT_MIN_INTERVAL (try 15-20).
#   403  -> Reddit refusing the datacenter IP class. No spacing fixes that;
#           comment these out, they will never work from CI.
# MULTIREDDITS, NOT ONE LINE PER SUBREDDIT — this is the whole fix for the
# HTTP_429 that zeroed this tier. Reddit rate-limits per IP (~10 req/min
# unauthenticated), so 11 separate requests failed no matter how far apart they
# were spaced. "r/a+b+c/.rss" returns all of them in ONE request, and
# "?limit=100" raises the page from 25 entries to 100. Three requests instead
# of eleven, each carrying ~100 entries: verified HTTP 200 with 100 entries.
#
# Keep these grouped. Splitting them back into one-line-per-subreddit is what
# broke it. To add a subreddit, append "+Name" to whichever group fits.
#
# IF THE HEALTH PANEL STILL SHOWS 429 FOR THESE, escalate in this order:
#   1. Merge all three groups into ONE line (one request/run). Cheapest fix —
#      costs breadth of a single page, needs no code and no credentials.
#   2. Raise REDDIT_MIN_INTERVAL to 20-30 in daily.yml.
#   3. Switch to Reddit's OAuth API. Registering a free script app lifts the
#      ceiling from ~10 req/min to ~100 QPM and is the only real fix if these
#      keep failing — it needs a client id/secret in repo secrets and a token
#      call in ingest.py.
